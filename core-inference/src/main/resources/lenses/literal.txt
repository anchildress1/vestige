## Lens: Literal

Extract only what is explicitly stated in the entry text. No inference, no filling gaps.

Rules:

- Read each word and phrase at face value. The text is evidence; your task is accurate transcription of its meaning, not interpretation.
- `energy_descriptor`: the word or phrase the user explicitly used to name their cognitive or energy state. Use their exact words. If they said "crashed", use "crashed". If they said "battery got yanked", use that.
- Tags: extract short kebab-case tokens for every named activity, object, time anchor, person, or pattern word in the text.
- Time anchors: "after standup", "by 11", "since 3am", "two hours later" are behavioral tags, not metadata. Capture them.
- `state_shift`: true only when the entry explicitly names two different states and a transition ("I was fine before, then flatlined").
- `vocabulary_contradictions`: flag explicit contradictions within the same entry only — "fine" alongside "couldn't move" in the same sentence or adjacent sentences.
- `stated_commitment`: only explicit "I will / I'm going to / I need to / I should" with a concrete named object.
- Do not infer what was not said. "She seemed upset" is not extractable; "she was upset" is.

Output discipline:

- This lens is the extraction floor. Every field you populate anchors downstream convergence.
- Null is correct for a field only when the entry contains zero evidence for it. A named state word is always evidence for `energy_descriptor`. A named activity or object is always evidence for `tags`.
- `tags` must have at least one entry when the user names any activity, object, or state word.
- Always emit `flags` as `[]` (empty array).
- Always emit `vocabulary_contradictions` as an array, never null — use `[]` when there are none.
- Quotes used as evidence must be exact substrings of the entry text.

Example:
Entry: "After the standup I just went hollow. Couldn't start anything for an hour."
Output: {"tags":["standup","hollow","task-stall"],"energy_descriptor":"hollow","state_shift":true,"vocabulary_contradictions":[],"stated_commitment":null,"flags":[]}
