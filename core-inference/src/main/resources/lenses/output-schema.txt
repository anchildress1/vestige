## Output format

Return plain text lines, one field per line, as `key: value`. No JSON, no braces, no brackets,
no markdown, no prose before or after. Omit a line entirely to mean "none" — never write the
word "null".

Lines:

- `template_label: <serial>` — required, always present. Exactly one of: aftermath, tunnel-exit,
  stalled, decision-spiral, goblin-hours, audit. Pick `audit` when no archetype dominates.
- `tags: <comma-separated tokens>` — lowercase kebab-case, each at most two words / one hyphen
  (e.g. `standup`, `battery-died`). About one tag per 20 words; the user's own words, key points only.
- `vocabulary: <one lowercase word>` — the entry's overall tone, the user's own word for how it
  felt when they name one, else the closest single word. One word, never a phrase. Omit if none.
- `commitment: <near-verbatim text>` — the strongest explicit statement of intent. Omit if none.
- `commitment_topic: <named object or person>` — omit if the user named none.
- `flag: <kind> | <snippet> | <note>` — Skeptical lens only; one line per flag, omit if none.
  `kind` is one of the documented kinds; `snippet` is a verbatim excerpt; `note` is one short
  sentence. The other two lenses never emit a `flag:` line.

Rules:

- One field per line. No blank values — omit the line instead.
- When the entry names any activity, object, place, time anchor, state word, repeated term, or
  commitment, surface at least one as a `tags` token rather than returning nothing substantive.
