## Lens: Skeptical

Apply an adversarial reading. Read what is NOT said. Populate the schema fields fully, then flag gaps, conflicts, and unsupported claims in `flags`.

Schema extraction — same surfaces as any lens:

Apply the surface rules exactly as any lens would: extract `energy_descriptor`, `state_shift`, `tags`, `vocabulary_contradictions`, and `stated_commitment` from the text. The surface files define what each field captures — follow them. Do the extraction fully and correctly first. Then layer the adversarial flags on top.

Adversarial layer — what to flag:

- `state-behavior-mismatch` — a state change is described ("I was fine before, then flatlined") but no triggering event is named.
  "Fine before standup, flattened by 11" — what happened in the standup? Not said. Flag it.
  "Went hollow. Couldn't start anything." — state described, cause absent.
- `commitment-without-anchor` — a modal commitment ("I should", "said I would") with no concrete object or deadline.
  "Said I would send the invoice" followed only by describing avoidance, no rescheduled date.
- `vocabulary-contradiction` — the user's own words point in two directions in the same entry.
  "Not tired exactly" + "battery got yanked" = negation then reassertion.
  "Technically awake, operationally not" = explicit self-contradiction.
  "Fine" in one sentence, "couldn't move" in the next.
- `unsupported-recurrence` — user says "again", "same thing", "third time" with no retrieved history to corroborate.
  "Crashed after standup again" when the history block shows no prior standup crashes.
- `time-inconsistency` — incompatible time anchors within the same entry for the same event.

`flags` output format:

- Each flag is `{kind, snippet, note}`. `kind` is one of the five above or `other`.
- `snippet` is a verbatim excerpt from the entry text. Quote the user's actual words.
- `note` is one short sentence naming the gap or conflict. No diagnosis, no advice, no framing.

Output discipline:

- Flags annotate the resolved fields — they do not replace them. Populate schema fields fully, then add flags.
- Convergence treats Skeptical flags as `canonical_with_conflict` when the other lenses agree on the underlying value.
- Genuinely unambiguous entries may produce zero flags. Do not manufacture contradictions.
- Always emit `vocabulary_contradictions` as an array, never null.
