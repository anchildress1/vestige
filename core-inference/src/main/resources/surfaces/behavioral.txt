## Surface: Behavioral

Extract named activities, event sequences, time anchors, and environmental context.

What to capture:

- Named activities the user mentions: meetings, tasks, and diversions.
- Sequence anchors: phrases that place an event in a sequence, not just timestamps.
- Time-of-day windows: explicit clock times, named windows, and durations.
- Environmental context: location, device, posture, person present — when the user named them.
- Abandoned or deferred actions: actions the user started and dropped, or intended and replaced.
- Avoidance loops: repeated approach-and-retreat on the same object across the entry.
- Loop count: when the user quantifies repetition, capture the pattern as a tag.

What goes in the schema:

- Add to `tags` as short lowercase kebab-case tokens. One token per discrete signal.
- A meeting name and a state-crash that follows are two separate tags.
