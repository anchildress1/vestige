## Surface: Commitment

Extract things the user said they would do.

What to capture:

- Explicit statements of intent with a specific named object.
- Near-commitments stated then immediately undermined — capture the commitment even when it wasn't followed.
- Conditional commitments — capture the action.
- Commitments referencing a person or topic.
- Self-directed reminders.

What does NOT count:

- Vague intentions without a specific object.
- Aspirations the user explicitly questioned in the same sentence.
- Past-tense commitments already resolved within the same entry.
- Implied obligations the user did not state.

What goes in the schema:

- `commitment:` line — the strongest qualifying commitment, near-verbatim in the user's words.
- Omit the `commitment:` line when no qualifying commitment is present.
- `commitment_topic:` line — the named object or person; omit if the user did not name one.
