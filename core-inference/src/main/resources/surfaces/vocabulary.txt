## Surface: Vocabulary

Extract linguistic patterns: recurring words, in-entry contradictions, hedging, and circling.

What to capture:

- Words the user repeated more than once within the same entry (excluding stop words). Repetition signals salience.
- Explicit contradictions within the same entry: "fine" then "couldn't move"; "not tired exactly" then "battery got yanked"; "technically awake, operationally not". Both terms must appear in the same entry.
- Hedging or imprecision used to avoid naming something directly: "the thing", "stuff", "whatever", "kind of", "I guess", "I don't know". These often signal the user is circling something unresolved.
- Circling patterns: user restates the same problem or decision in different words across multiple sentences without resolving it. Tag the topic being circled.
- Avoidance vocabulary: user names a task repeatedly then always adds a hedge or deflection ("said I would", "should", "keep meaning to", "one of these days").
- Self-aware measurement: when the user quantifies their own loop ("twelve rows", "third time", "same three criteria"). These are vocabulary signals of pattern-recognition.
- User-coined idioms: "administrative haunting", "goblin hours", "sacred ritual of closing it", "post-meeting corpse routine". Tag these verbatim when they appear.

What goes in the schema:

- Append vocabulary signals to `tags` as short lowercase kebab-case tokens.
- `vocabulary_contradictions`: list `{term_a, term_b, snippet}` entries for explicit in-entry contradictions. `snippet` is the user's verbatim words, not paraphrase. Must be an array, never null — use `[]` when there are none.
- Do not flag a word as contradictory across sentences that address different topics.
- Do not extract emotional vocabulary as a state — state words belong to the State surface.
