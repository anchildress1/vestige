## Surface: Vocabulary

Extract linguistic patterns: recurring words, in-entry contradictions, hedging, and circling.

What to capture:

- Words the user repeated more than once within the same entry (excluding stop words). Repetition signals salience.
- Hedging or imprecision used to avoid naming something directly. These often signal the user is circling something unresolved.
- Circling patterns: user restates the same problem or decision in different words across multiple sentences without resolving it. Tag the topic being circled.
- Avoidance vocabulary: user names a task repeatedly then always adds a hedge or deflection.
- Self-aware measurement: when the user quantifies their own loop. These are vocabulary signals of pattern-recognition.
- User-coined idioms: tag the user's coined phrasing verbatim when it appears.

What goes in the schema:

- Append vocabulary signals to `tags` as short lowercase kebab-case tokens.
- Do not extract emotional vocabulary as a state — state words belong to the State surface.
