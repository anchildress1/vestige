## What this is

Two changes aimed at making the model **pick the template correctly at the root**, not having a
deterministic map decide it after the fact:

1. **Un-defer `template_label`.** An earlier attempt made the resolver defer a converged `audit` to
   `TemplateLabeler`'s `tag → template` map — that improved the *final* label but did nothing to make
   the model pick. Reverted. The model's converged pick (CONSENSUS / CONSENSUS_WITH_CONFLICT) now
   stands; the labeler is fallback-only (non-convergence, unknown serial, or the timestamp-only
   goblin-hours case the entry text doesn't name).
2. **Remove the `audit` crutch from the schema.** `output-schema.txt` said *"Pick `audit` when no
   archetype dominates"* — an explicit default that, with the model already audit-biased, collapsed
   8/12 to AUDIT. Reworded to *"Commit to the one archetype that best fits … use `audit` only when
   the entry genuinely matches none of the others."* **No per-archetype descriptions added** — that
   is the prompt bloat that has broken picking before.

The per-lens vocabulary sampler (`VOCAB_DIVERSITY_SAMPLER` on the Inferential lens) is unchanged from
the prior commit and still in effect.

## Verdict

**PASS — the model now commits.** 12/12 `Success`, 3/3 lenses parse, single attempt, zero retries.
`template_label` resolved **CONSENSUS on all 12** — every final label below is the model's own
converged pick, not a labeler override.

- **AUDIT dropped 8/12 → 4/12.** And the four that remain are genuine: `audit-double-check`,
  `both-tanks-empty` (all three lenses say audit), plus `wired-third-night` / `anxious` (majority
  audit). The catch-all is now used as a catch-all, not a default.
- **Six distinct archetypes in play** (AFTERMATH ×3, TUNNEL_EXIT ×2, AUDIT ×4, GOBLIN_HOURS,
  DECISION_SPIRAL, STALLED) — up from near-total audit.
- **The model reached GOBLIN_HOURS from the text itself** (`awake-2am-spinning`: LITERAL + INFERENTIAL
  both `goblin-hours`, from "Still awake at 2am"). No deterministic time-check involved.
- **Vocabulary held:** `weary` 10/12 → 6/12, distinct tone words 3 → 7 (`weird`, `restless`,
  `sudden`, `wired`, `anxious`, `contradictory`).

## Honest reads — the picks aren't all perfect

Committing has a cost: a couple of picks are the model's genuine-but-debatable read rather than
clearly correct.
- `crashed-3pm-no-warning` → **STALLED** (LITERAL + INFERENTIAL), where AFTERMATH ("Crashed at 3pm")
  is the more obvious read; the model anchored on "had to give up on the afternoon."
- `tuesday-stalled` → **AFTERMATH**, where STALLED ("completely unable to get moving") is arguably
  closer.

These are the model's own reads — the point of this change is that the model *picks*, and it now does
so across the full archetype range instead of hiding behind `audit`. Tightening the borderline reads
is a prompt-quality follow-up, not a deterministic override.

## Caveats

- **Latency rose to 38.4 s mean** (from ~21–23 s earlier today). This was the third consecutive heavy
  GPU pass of the session; the per-lens times roughly doubled across the board, which reads as thermal
  throttling on the device rather than a cost of the reword (the prompt grew only ~99 chars). Re-measure
  on a cold device before treating it as a regression.
- **Single run**, seeded sampler — reproducible per prompt; determinism not separately re-verified.
- **Cross-branch baseline.** The 2026-05-23 baseline ran on `feat/recurrence-vocab-wiring`; the
  archetype-commit and vocabulary deltas are visible directly in this run's per-lens data regardless.

## Follow-ups
