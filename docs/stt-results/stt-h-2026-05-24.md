## What this is

The first run after two deterministic-side fixes:

1. **AUDIT catch-all deferral** (`BackgroundExtractionWorker.resolveTemplateLabel`). A converged model
   `audit` is the lenses conceding "no archetype," so it now yields to the deterministic
   `TemplateLabeler` whenever the tag tree / goblin-hours rules place the entry. A *specific* model
   pick still wins outright. No prompt change.
2. **Per-lens vocabulary sampler** (`LiteRtLmEngine.VOCAB_DIVERSITY_SAMPLER`, applied to the
   Inferential lens only via `BackgroundExtractionWorker.samplerForLens`). Greedy `topK=1` decode
   collapsed the `vocabulary` surface to one word on every entry; the Inferential lens now samples
   for lexical variety while Literal + Skeptical stay greedy so tag / label convergence keeps its
   determinism. The sampler is seeded, so it is reproducible per prompt — variety is across entries,
   not across re-runs.

## Verdict

**PASS (parse + convergence).** 12/12 `Success`, 3/3 lenses parse every entry, single attempt, zero
retries, zero parse failures. The flat-line contract holds across all 36 calls with the Inferential
lens sampling.

**Fix 1 — AUDIT deferral fires and is correct where tags carry an archetype:**
- `standup-crash-cycle`: model `audit` (CONSENSUS) → **deferred to AFTERMATH** (`crashed` tag). Was
  AUDIT in the 2026-05-23 baseline. Clean deterministic promotion.
- `crashed-3pm-no-warning`: model `audit` → **deferred to AFTERMATH** (`crashed` tag).
- Net AUDIT *count* is unchanged at 8/12 — **not** because the fix failed, but because most of the
  remaining AUDIT entries don't carry an archetype-bearing tag for the labeler to act on
  (`tuesday-stalled` tagged `heavier`/`slower`, not `stalled`; `awake-2am-spinning` has no
  `late-night`/`overnight` tag to trip goblin-hours; etc.). That is a tag-coverage gap in the
  *model's* output, not a resolver gap — see Follow-ups.

**Fix 2 — vocabulary diversifies:**
- `weary` dropped from **10/12 → 7/12**; distinct tone words rose **3 → 5** (`restless` ×2,
  `contradictory`, `sudden`, `weird`).
- `both-tanks-empty` now reads **`contradictory` (CONSENSUS)** — a genuinely better tone read than
  the baseline `weary`, and it kept consensus.

**Tradeoffs measured (honest):**
- **One label regression.** `shipped-then-wall` went AFTERMATH (baseline) → **AUDIT**. The seeded
  Inferential lens shifted its template vote (`LITERAL=aftermath, INFERENTIAL=audit, SKEPTICAL=audit`
  → majority `audit`) and the model tagged `hit-wall` (no archetype set), so the labeler couldn't
  rescue it. Sampling the Inferential lens perturbs the fields it co-votes on (tags / label), not
  just vocabulary — this is the cost of per-lens sampling on a shared generation call.
- **Vocabulary verdict softening.** `awake-2am-spinning` and `wired-third-night` diversified to
  `restless` but dropped to **CANDIDATE** (Literal/Skeptical greedy didn't name the same word, so no
  corroboration). CANDIDATE tone words are lower-confidence and may not feed vocab-frequency
  clustering — structural to per-lens sampling, not a temperature artifact.

## Caveats

- **Cross-branch baseline.** The 2026-05-23 baseline ran on `feat/recurrence-vocab-wiring`
  (prompt 8535 chars); this run is on `fix/readme-links-and-extraction-tuning` (8596 chars). The
  ~61-char prompt difference is a pre-existing code-state delta, not introduced here, but it means
  the before/after is not a perfectly isolated A/B. The deferral-fix promotions and the vocabulary
  diversity are visible directly in this run's per-lens data regardless of the baseline.
- **Single run.** Determinism re-verification was not repeated; the Inferential sampler is seeded
  (`seed=42`) so the run is reproducible per prompt.

## Follow-ups

- **AUDIT count is gated on tag coverage, not the resolver.** Reducing it further means the model
  emitting archetype-bearing tags (`stalled`, `late-night`) on the entries that warrant them, or an
  evidence-driven widening of `TemplateLabeler` tag sets. Neither should be done reactively /
  pre-demo without a dedicated STT pass — tracked as labeler tag-coverage tuning.
- **Per-lens sampler couples vocabulary to label votes.** If the `shipped-then-wall`-style
  perturbation matters more than the vocabulary win, a lower Inferential temperature (e.g. 0.7) trades
  some variety for less label drift — one more on-device run to calibrate.
